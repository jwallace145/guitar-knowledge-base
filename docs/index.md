# Guitar Knowledge Base

A personal, public set of notes on guitar theory and study. It is organized so that
each idea has one home and links out to the others.

## Sections

- **[Theory](theory/index.md)**: intervals, scales, modes, and harmony. The vocabulary
  everything else is written in.
- **[Fretboard](fretboard/index.md)**: CAGED, positions, and triads by string set. Where
  theory lands on the instrument.
- **[Techniques](techniques/index.md)**: picking, legato, bends, vibrato, and the drills
  that build them.
- **[Repertoire](repertoire/index.md)**: exercises, original material, and song analyses.

See [About](about.md) for what this is and how it is built.
