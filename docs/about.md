# About

## What this is

A guitar theory and study knowledge base. It collects the things worth writing down
while learning the instrument: theory, how that theory maps onto the fretboard,
technique notes, and analyses of the music being studied.

It is a living document. Pages get revised as understanding improves.

## How it is built

- Content is Markdown in the `docs/` directory.
- The site is generated with [Zensical](https://zensical.org/), a static site generator
  from the team behind Material for MkDocs.
- It is deployed to GitHub Pages by GitHub Actions on every push to `main`, and served at
  [guitar.jwall.engineering](https://guitar.jwall.engineering/).
- Releases and the changelog are managed by Release Please from Conventional Commits.

Source: [jwallace145/guitar-knowledge-base](https://github.com/jwallace145/guitar-knowledge-base).
